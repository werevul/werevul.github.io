# WereVul — Project Website

🌐 **Live site:** https://werevul.github.io

GitHub Pages site for the WereVul CS491 Senior Project.

## Setup

1. Create a GitHub repo named `werevul-site` (or any name) under your org/user
2. Push this folder to the repo
3. Go to **Settings → Pages → Source: main branch / root**
4. Your site will be live at `https://YOUR_USERNAME.github.io/werevul-site`

## Customization

- Replace `YOUR_ORG/werevul` in `index.html` with the actual GitHub repo URL
- Add GitHub usernames for each team member in the Team section (uncomment the `<a>` tags)
- Replace `#` hrefs in the Reports section with actual PDF/slide links
- Update the footer university name if needed
