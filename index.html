Pronunciation: "wear-ee-vul"  ·  were (werewolf) + vul (vulnerability)
GitHub Repo Learn More

Project Overview

What is WereVul?

🎯

Core Goal

Develop an LLM-assisted framework to detect, localize, and propose fixes for security vulnerabilities in Java repositories.

📂

Input

Any Java source code repository — large-scale or small, open-source or private.

🔍

Analysis

Static analysis, file/function localization, and LLM-based vulnerability reasoning.

📋

Output

Vulnerability reports with CWE classification, affected code locations, explanations, and suggested patches.

System Architecture

How WereVul Works

Step 1

Java Repository

Target source code base for analysis.

Step 2

Initial code scan & parsing.

Step 3

Localization

File & function targeting.

AI Detection

LLM vulnerability identification.

Step 5

CWE Class

Categorize vulnerability types.

Step 6 · Optional

Step 7

Testing

Compilation & verification.

Step 8

Final Report

Validated security result.

Capabilities

Key Features

Detects vulnerabilities in repositories
Deep context scanning across project files
Identifies affected files, functions, and code lines
Precise localization down to line level
Classifies findings using CWE categories
Standardized weakness taxonomy
Supports locally running AI models for code privacy
On-premise execution — source code never leaves your environment
Produces clear and actionable vulnerability reports
Developer-friendly insights
Generates AI-assisted repair suggestions (optional)
Automated patch proposal with compilation & regression verification

Innovation

What Makes WereVul Different

Dual-approach vulnerability detection
Combines static analysis with local code language models
Optimized context windows
Reduces large repositories before sending code to the AI model
Complete data privacy & security
Keeps source code inside the local environment — no cloud upload required
Strict patch verification
Does not accept an AI-generated patch without validation
Automated safety checks
Uses Proof-of-Vulnerability and regression tests
