About

WHAT IS WEREVUL

WereVul is an LLM-assisted framework that detects, localizes, and proposes fixes for security vulnerabilities in Java repositories. It combines static analysis with locally running language models to produce CWE-classified vulnerability reports — without ever sending your source code to the cloud.
